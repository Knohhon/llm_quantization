Certainly! Below is a Python function for implementing binary search. Binary search is a search algorithm that finds a specific element in a sorted list by repeatedly dividing the search interval in half.

### Example:

```python
def binary_search(arr, target):
    """
    Perform binary search on a sorted list.
    """
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return None

# Example usage
```
